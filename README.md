# LUNE Studio — Website thời trang

Website tĩnh demo cho học phần **Thiết kế Web**. Xây dựng bằng HTML5, CSS3 và JavaScript thuần; có tích hợp Animate.css và AOS qua CDN.

## File trong dự án

- `index.html` — nội dung và cấu trúc Semantic HTML5.
- `style.css` — CSS Variables, bố cục Grid/Flexbox, responsive, hover/focus.
- `script.js` — lọc sản phẩm, tìm kiếm, giỏ hàng demo, menu mobile và form nhận tin demo.
- `PROMPT_LOG.md` — nhật ký Prompt Engineering mẫu; hãy điền MSSV và cá nhân hóa trước khi nộp.

## Chạy thử

Mở `index.html` bằng trình duyệt. Cần có internet để tải Google Fonts, hình ảnh và thư viện Animate.css/AOS từ CDN.

## Đưa lên GitHub Pages

1. Tạo repository công khai theo cú pháp mà giảng viên yêu cầu: `Ten_Ho_MSSV`.
2. Upload **các file bên trong thư mục này** lên thư mục gốc của repository: `index.html`, `style.css`, `script.js`, `PROMPT_LOG.md`, `README.md`.
3. Vào **Settings → Pages**.
4. Trong **Build and deployment**, chọn **Deploy from a branch**; chọn nhánh `main` và thư mục `/(root)`, sau đó Save.
5. Đợi GitHub Pages hoàn tất triển khai. Mở đường dẫn live được hiển thị trong phần Pages để kiểm tra, rồi dán link đó vào phần mô tả repository.

## Trước khi nộp

- [ ] Điền MSSV vào `PROMPT_LOG.md`.
- [ ] Đổi tên repository đúng cú pháp yêu cầu.
- [ ] Kiểm tra trang trên cả điện thoại và máy tính.
- [ ] Thử menu, bộ lọc, tìm kiếm, giỏ hàng và form đăng ký.
- [ ] Xác nhận GitHub Pages hoạt động và thêm link live vào mô tả repository.
- [ ] Chỉnh nhật ký prompt để phản ánh đúng phần sinh viên đã thực hiện.

**Lưu ý:** Giỏ hàng và đăng ký nhận tin chỉ minh họa phía giao diện, chưa kết nối backend/thanh toán thật. Ảnh sản phẩm được tải từ Unsplash qua URL bên ngoài.
